# Changelog

## 1.6.0 (1.60) — 2026-10-27

Reworked the application around one shell, four primary workspaces, contextual views and a default analysis overview. BAC and caffeine have aligned separate plots, distinct trace patterns and a shared inspector. Added quick intake/person editing, parameter search and direct validated parameter dialogs with Undo.

Separated scientific depth from explanation support, spacing, text size, line spacing and Focus layout. Added grouped appearance/motion/notification/unit preferences, interface-profile import/export, grouped resets and remembered optional panels. Removed duplicate headers, navigation and current-result announcements. Updated three-level guidance and report plots.

Retained engine 0.4.4, constants 0.3.0, scenario schema 0.8.2 and session schema 1.0.0. Added trajectory compatibility fixtures, three-browser keyboard/accessibility/responsive checks and post-deployment byte verification. Existing session, recovery, comparison, export, standalone and offline/update workflows remain release gates.

## 1.5.0 — 2026-10-27

Added Session chronology with stable model zero, IANA calendar display, explicit clock-change resolution, grouped intake/meal shifts and duplication, and inspection markers. Added shared bounded history, named saved states, opt-in recovery and portable session documents with legacy scenario import.

Added accepted-state compartment and rate explanations, defined PD index descriptions, conditional intake-removal analysis, explicit captured A/B input and profile differences, metric deltas and complete threshold intervals.

Added frozen HTML reports at three depths, an offline application cache, update recovery, install support and a self-contained standalone build. Added Default, Detailed and Expert operating guides with action/result/check instructions, worked examples, glossary and troubleshooting.

Recovered the 1.0.1 application into reproducible source modules and added numerical, state, browser, offline lifecycle and deterministic-build verification. Engine 0.4.4, constants 0.3.0 and scenario schema 0.8.2 are retained.

## 1.0.1 — 2026-10-25

Maintenance release addressing the original stress-test findings, including repeated threshold episodes, full-horizon data handling, accepted-state provenance, validation and release identity. Shipped engine 0.4.4 and a build manifest.

## 1.0.0

Initial hosted release. The original HTML and verification files are preserved in the release archive.
