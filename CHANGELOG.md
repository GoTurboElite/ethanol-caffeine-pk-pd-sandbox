# Changelog

## 2.0 interface restoration - 2026-10-28

Restored the input workspace's live BAC rings and concentration graph, including responsive three-column, two-column and stacked layouts. Fresh browser and installed-app launches now open Session → Inputs. Explicit analysis and scientific links remain directly accessible.

## 2.0.0 — 2026-10-28

Added a local scientific workbench with timestamped observations, explicit matrices/error scales and held-out evaluation. Added bounded one/two-parameter calibration with sensitivity checks, objective support and undoable named application. Added seeded joint uncertainty, paired A/B draws, conditional threshold fractions and censored final-return summaries.

Added four published group-level Cmax benchmarks from two studies, a benchmark-only feeding hypothesis, evidence inspection and three-level operating instructions. Retained the v1.60 reference PK equations and heuristic response classifications. Session wrapper 1.1.0 preserves scientific inputs and result archives while importing earlier sessions. Reports and standalone delivery include the workbench. Production checks cover pkpd.goturbo.one and the retained Pages alias through the unchanged GitHub-connected Pages architecture.

## 1.6.0 (1.60) — 2026-10-27

Reworked the application around one shell, four primary workspaces, contextual views and a default analysis overview. BAC and caffeine have aligned separate plots, distinct trace patterns and a shared inspector. Added quick intake/person editing, parameter search and direct validated parameter dialogs with Undo.

Separated scientific depth from explanation support, spacing, text size, line spacing and Focus layout. Added grouped appearance/motion/notification/unit preferences, interface-profile import/export, grouped resets and remembered optional panels. Removed duplicate headers, navigation and current-result announcements. Updated three-level guidance and report plots.

Retained engine 0.4.4, constants 0.3.0, scenario schema 0.8.2 and session schema 1.0.0. Added trajectory compatibility fixtures, three-browser keyboard/accessibility/responsive checks and post-deployment byte verification. Existing session, recovery, comparison, export, standalone and offline/update workflows remain release gates.

Corrected cached navigation on Cloudflare Pages: redirected cached HTML is copied into a fresh response before serving a navigation, and cache-read failures fall back to the network. Added Cloudflare-style redirect fixtures and hosted-browser reload checks.

## 1.5.0 — 2026-10-27

Added Session chronology with stable model zero, IANA calendar display, explicit clock-change resolution, grouped intake/meal shifts and duplication, and inspection markers. Added accepted-state compartment and rate explanations, defined PD index descriptions, conditional intake-removal analysis, explicit captured A/B input and profile differences, metric deltas and complete threshold intervals.

Added frozen HTML reports at three depths, an offline application cache, update recovery, install support and a self-contained standalone build. Added Default, Detailed and Expert operating guides with action/result/check instructions, worked examples, glossary and troubleshooting.

Recovered the 1.0.1 application into reproducible source modules and added numerical, state, browser, offline lifecycle and deterministic-build verification. Engine 0.4.4, constants 0.3.0 and scenario schema 0.8.2 are retained.
