## Inspection and mass accounting

Explain and dense Analysis views share the inspector in `src/ui/mechanism.jsx` and the projection in `src/science/mechanism.mjs`. The optional inspection return from the retained kernel derivative supplies administration, gastric emptying, site-specific uptake, first-pass extraction, systemic appearance, elimination and metabolite fluxes. The selected instant uses the event and meal state at that instant. Dense compartment states use linear interpolation, with an explicit correction for discontinuous oral boluses between knots. A bolus has a mass and event time. The finite input-rate term describes continuous administration. Plots sample 97 regularly spaced display times plus administration and meal boundaries. Straight display segments can approximate sharp transitions. The inspector and exports evaluate the actual selected time.

Ethanol residual in grams equals initial plus administered mass less gastric, intestinal and systemic mass, first-pass extraction and systemic elimination. Caffeine residual in parent-equivalent milligrams subtracts remaining parent, unrouted parent elimination and retained plus eliminated paraxanthine converted through the parent/metabolite molar mass ratio. Counting all eliminated parent again would double-count metabolite formation. Relative residual divides absolute residual by initial plus administered mass and is undefined at zero supply. Ethanol systemic appearance follows bioavailable uptake. Michaelis–Menten elimination uses the resolved Vmax, clearance multiplier, Km and current BAC. The zero-order branch reports the capacity available at the current state, with clearance limited by appearance at depletion. Caffeine clearance is effective k times apparent distribution volume. These are mathematical pools. PK and heuristic response outputs retain distinct interpretations and identical depth-independent numerical values.

The HTML report at Detailed or Expert depth includes the selected-time ledger. Analytical JSON includes canonical units, full-precision quantities and captured A/B ledgers. The older finite-interval appearance estimator remains separately labelled in Explain.

## Scientific computations

A common-value sweep assigns each grid coordinate to both captured inputs, including scenarios with different parameter baselines. The continuous response between coordinates remains unresolved. Promoting a member edits the experimental draft and preserves the protected reference.

For a two-parameter fit, each of seven fixed log-grid values per axis starts from the lowest evaluated cell on the nuisance axis. A bounded golden-section search refines that basin, retaining grid boundaries as candidates. The bracket tolerance is 0.1% of the nuisance log range with at most 18 extra evaluations per profile row. The record contains objective, change from fitted cost, nuisance optimum, boundary contact, stopping status and simulation count. This is descriptive local basin refinement. Disconnected minima can be missed. A materially lower profile evaluation blocks application of the original fitted combination. Weighted sensitivity columns and log concentration elasticities are available at quantified calibration times. Zero predictions have no log elasticity. Local conditioning gives limited information about global identifiability.

Expert Explain compares the accepted event-segmented RK4 configuration with a run at half its actual selected internal step. It records concentration samples, peaks and times, AUC, threshold status and resolved return, maximum absolute mass residuals and the pre-clamp negative count. Comparative concentration extrema still use the union of dense knots with piecewise-linear interpolation.

Prospective measurement sampling is opt-in. Additive Gaussian error uses per-analyte SD in canonical concentration units and permits negative readings. Proportional error draws C × exp(sZ − s²/2), where s² = ln(1 + CV²). Its conditional mean is C and zero concentration is preserved. A separate seeded stream produces independent errors for times, analytes and A/B sides. Paired exposure uses shared parameter draws as before. Zero error recovers the latent grid exactly. Predictive quantiles are pointwise and describe one prospective observation at each time. Existing observation SD and published SEM are never substituted for the prospective measurement model.
