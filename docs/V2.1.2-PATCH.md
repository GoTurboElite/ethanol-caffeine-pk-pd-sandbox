# v2.1.2 maintenance release

This patch corrects observation-conversion integrity and presentation defects identified in the 31 October 2026 live appraisal. It retains reference-1.60, PK engine 0.4.4, constants 0.3.0, scenario schema 0.8.2 and the existing PK/PD equations and defaults.

## Observation integrity and compatibility

New CSV/manual observations in plasma caffeine or whole-blood ethanol accept an absent matrix factor or 1. A non-unit factor for an already canonical matrix is rejected with an actionable error. Unknown CSV headers are rejected before review to avoid silently dropping misspelled provenance fields.

Historical scientific documents retain their original native-matrix factors, values, SDs and source text. They remain exportable and undoable. A visible observation warning identifies affected rows. Evaluation, fitting, uncertainty and fit application are blocked until affected rows are explicitly corrected or removed. The independent published benchmark task remains available. Editing exposes the original factor and requires clearing it or entering 1; changing the declared matrix instead requires its conversion source. Undo restores the original row and the analysis block. The scientific document remains schema 1.1.0 because the stored shape is unchanged; scientific validation/workbench revision 1.0.1 is included in input identity. Imported result records remain archives requiring recomputation.

Observation review, committed rows and frozen reports show original units/matrix, conversion factor, canonical concentration and effective error scale. Supplied SDs follow unit/matrix conversion; absent SDs retain the declared canonical default error scale. Missing row-specific CSV conversion sources are explicitly flagged; they are not represented as independently verified.

## Result presentation and plotting

Input results and aligned plots identify simulated concentrations and unvalidated heuristic interpretation near the results. Reports carry the same limitation, including that a threshold crossing does not establish recovery or fitness. Current reference labels use “Configured BAC reference”; the interval table uses “Last downward crossing in schedule.” Historical numeric keys and thresholds remain unchanged.

Published benchmark tables and reports add absolute and percentage discrepancies beside standardized error. The existing two-reported-SD descriptive screen is retained and explicitly distinguished from individual/full-trajectory validation. No parameters are tuned to the four benchmark summaries.

Intake bars in Analysis and reports clip overlapping negative-time administrations to the visible horizon. Initial pending calculations use neutral status wording, without visible repair actions or invalid step badges. Expert initial compartments have readable labels and units. Small-screen toolbar spacing is reduced, secondary navigation indicates additional views, and the three depths have a concise explanation. Existing keyboard cursor values and screen-reader text are preserved.
