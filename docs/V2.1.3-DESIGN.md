## Implemented architecture and behaviour

- `src/session/differences.mjs` compares immutable accepted inputs with the committed draft. It recursively enumerates changed leaves, including nested model constants, and matches intake/meal events by ID. Additions, removals, timing, composition and order changes are explicit. Categories and paths have deterministic ordering; registered labels/units and shared human-readable fallbacks are used. Optional absent/undefined fields do not create empty schedule differences. `accepted.mjs` retains the established snapshot, currentness and horizon contract. Invalid text is not misrepresented as a committed parameter.
- `src/ui/context.jsx` displays pending categories and a collapsed grouped comparison. Unchanged parameters stay outside the primary display. Expert adds input paths. Retained plots, peaks, threshold intervals, numeric inspection and labels continue using the accepted snapshot and its horizon while the draft is pending, invalid or failed.
- `src/session/surfaces.mjs` implements an ephemeral single-use activation intent. `runtime.mjs` coordinates route cancellation and the existing legacy surface controller; `index.jsx` consumes the request after Inputs commits. Navigation interruptions cancel requests; history cannot replay them. The legacy modal manager now completes inert-state removal and focus restoration after the React commit using microtasks, replacing timing guesses. A settled event restores an available originating action or a meaningful destination fallback. Route transitions focus a destination heading when the old focused surface disappears. These intents are not scientific/session data.
- `observation-list.jsx` and `observation-details.mjs` share committed and CSV projections: six primary columns plus accessible expandable detail rows. Details preserve IDs, exact elapsed time, qualifier, original value/unit/matrix, role, supplied SD, conversion factor/source, canonical value, effective error scale and review status. Positive small measurements remain nonzero. The review filter includes conversion assumptions, missing SD, upper limits and historical correction requirements; flags are qualifications, not independent provenance verification. Original source/metadata remain exportable.
- Observation editing keeps the selected ID, returns focus to its action and restores scroll position. Revealing additional rows focuses the first new record. Duplicate labels receive ID-qualified accessible action names. At narrow widths primary rows become compact labelled grids, retaining table roles and discoverable actions. CSV confirmation focuses and reveals the committed dataset heading after its confirmation control disappears. CSV validation, stale-preview invalidation, explicit confirmation, replacement and atomic Undo remain unchanged.
- Graphical inspection now exposes horizontal slider semantics and shared time/BAC/caffeine value text rather than an interactive image. Numeric and range controls remain alternatives. Pointer capture clamps mouse drags; touch capture waits for horizontal intent so vertical scrolling remains available. Cancelled/lost capture resets interaction. A shared formatter and one deliberate announcement path avoid simultaneous competing live regions. Full-horizon rendering, independent overlay scales and concentration calculations remain unchanged.
- `scientific-state.jsx` connects the dataset reference and existing result validity with the accepted snapshot, body mass and horizon, and links to its inspection. Observation-local Evaluation/Calibration actions reduce returning to global navigation. Existing scientific search, nested active routes and imported-result restrictions remain authoritative. Guidance, release history, standalone download and offline identities are updated together.

## Verification and objective indicators

`test/refinement.mjs` adds deterministic coverage for recursive/nested differences, event removal/addition/timing/composition, meal changes, model constants, absent optional fields, both draft-horizon directions, invalid/running/failed/cancelled retention, activation supersession/cancellation/history and 200-row metadata projection. Existing numerical/state/science/session suites remain release gates.

`test/refinement-browser.mjs` adds nine groups: Default construction/accepted inspection; Detailed changes and accepted horizon with Undo/Redo/session import; route readiness/interruption/Back/Forward/repeat activation/focus; Expert row-200 editing/provenance/Undo; CSV complete review, stale guards and scientific continuation; narrow/enlarged layouts at all three depths; pointer capture/touch-intent/overlay accessibility; a keyboard-only three-archetype sequence; and absence of unhandled errors. The same script is required in Chromium, Firefox and WebKit CI, alongside every retained browser, accessibility, integrity, offline and hosted suite.

Local Chromium completed all nine new groups. At 390 px, the observation table measured 330 px in each scientific-depth setting versus baseline 959 px. The keyboard-only input → accepted inspection → PK edit/difference → observation provenance → Evaluation sequence completed with 22 counted activation/navigation keystrokes or clicks and four hash transitions, with explicit focus assertions. The row-200 scenario used ten counted actions and one transition. These counters exclude typing, programmatic fixture setup and some direct test setup actions. They describe repeatable scripted scenarios, not an efficiency comparison with human participants or a human usability study. Generated JSON captures the exact engine, results, measurements and errors; screenshots and full suite evidence are attached to CI.

Windows local verification uses installed Chromium; Linux CI supplies Firefox and WebKit as well. Release promotion requires numerical/deterministic-build gates, all three browser jobs and the exact Cloudflare preview. Main then reruns those gates against both hostnames and verifies exact HTML, standalone and worker bytes. The final deployment identity and CI evidence are reported with the release PR and delivery report; this document does not presume pending jobs have succeeded.

## Compatibility and limits

No numerical equations, scientific defaults, profile, reference constants, calibration/uncertainty algorithms or evidence data changed. Engine 0.4.4, constants 0.3.0, reference-1.60, scenario 0.8.2, session/scientific document 1.1.0, workbench validation 1.0.1 and evidence 2026-10-28.1 remain. No schema migration was introduced. Legacy native-matrix conversion factors remain preserved, explicitly correctable and blocked from scientific analysis until resolved. Imported result archives still require recomputation. Existing bounded history, saved states, reports, standalone and offline/update recovery remain regression gates. Archived v2.1.2 standalone bytes are retained.

Outstanding manual validation: NVDA/JAWS/VoiceOver task execution and announcement quality, browser/OS text zoom beyond automated enlarged text, physical iOS/Android horizontal inspection versus vertical scrolling, interrupted device gestures, installed-app lifecycle and observed comprehension across the three archetypes. Automated axe scans and emulated pointers do not complete these assessments. No claim of individual predictive validity is added: the retained empirical corpus remains four group Cmax summaries from two studies.

Residual v2.1.x work is to resolve defects found by those manual assessments and any deployment-specific regressions. General zoom/pan, advanced overlays, experimental trajectory comparisons, larger data management and broader empirical validation belong to v2.2 or separately scoped scientific development. The release deliberately retains the full-horizon plot and existing 200-row dataset limit.
