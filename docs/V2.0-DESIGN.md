# v2.0 development and scientific contract

## Release purpose

The scientific workbench adds observations, bounded parameter calibration, declared uncertainty distributions, empirical-summary evaluation and evidence inspection while retaining the v1.60 reference equations. The official hostname is pkpd.goturbo.one; the Pages alias remains available. The existing GitHub-to-Pages deployment architecture is preserved.

## Scientific identity

The default model profile is reference-1.60, engine 0.4.4 and constants 0.3.0. Main-scenario PK trajectories retain their prior numerical behaviour. The application version advances independently to 2.0.0. The built-in source registry distinguishes literature priors, engineering defaults and heuristics. A fit of concentration dynamics leaves behavioural and PD coefficient classifications unchanged.

## Observations

CSV headers require time_h or time_iso, analyte, value, unit and matrix. Optional columns are role, sd, qualifier, matrix_factor and label. time_iso requires an explicit timezone offset or Z and is converted relative to the current model-zero anchor. Up to 200 rows are accepted atomically. Ethanol uses g/dL, g/L or mg/dL; caffeine uses mg/L, ng/mL or ug/mL. Whole-blood ethanol and plasma caffeine match the model observation convention. Supported alternatives require a declared matrix factor; breath alcohol needs a separate observation model and is rejected.

Roles are calibration or evaluation, with evaluation as the default. Qualifier < denotes an upper limit. Residual metrics separate quantified rows from censored rows. Missing SD uses an explicit error scale of 0.002 g/dL ethanol or 0.1 mg/L caffeine. A source/assumption field accompanies the dataset. The synthetic recovery example is prominently labelled and contributes no empirical validation.

## Calibration

One or two distinct registered quantities can be fitted. Candidates are effective caffeine half-life, ethanol elimination multiplier, caffeine apparent Vd, caffeine absorption multiplier and gastric-emptying multiplier. Active-mode checks prevent fitting an ignored half-life field. The parameter bounds are registered physical/support limits and are exported with each job.

The optimiser performs bounded log-parameter coordinate searches with multiple starts and a 40-320 objective-evaluation budget. It uses calibration rows matching fitted analytes; evaluation rows remain excluded. Quantified observations use weighted squared residuals. Upper limits use a one-sided squared penalty with explicitly limited interpretation. Finite-difference local sensitivities check dependence; absolute sensitivity correlation of at least 0.995 or negligible sensitivity disables application. Contact within 1% of a parameter bound also disables application. A one-dimensional coarse objective profile can supply support under a stated Gaussian-SD assumption.

Application is explicit, undoable and named. Imported result archives remain archival until recomputed. These estimates are conditional on the chosen model, inputs and measurement semantics. Population fitting, general behavioural fitting and broad clinical-population claims are outside this release.

## Sampling

The sampler supports 16-256 draws and up to three registered parameters. Mulberry32 and Box-Muller transforms provide a reproducible unsigned 32-bit seed stream. A positive-definite Gaussian-copula matrix specifies latent dependence. Uniform and triangular distributions use inverse transforms; lognormal reference values are medians and CV is declared. Whole-draw rejection enforces bounds, with a finite rejection budget.

Paired A/B mode requires equal horizons and equal reference values for the selected uncertain quantities. Both scenarios receive identical absolute parameter values. Time-grid summaries use 97 reporting positions; accepted dense trajectories determine peaks and threshold outcomes. Each grid position reports sampled P05, P50 and P95 and a conditional threshold-exceedance fraction. Final-return quantiles are explicitly conditional on resolved trajectories; never-exceeded cases receive 0 h and unresolved cases remain counted.

The initial parameter set represents specified parameter uncertainty. Dose/timing distributions, hierarchical population fitting and structural-model averaging require subsequent extensions. The interface and export state these boundaries.

## Published benchmark corpus

The corpus transcribes group-level Cmax facts, with original source links and unit conversion, from Laizure et al. 2017 (PMC5698589, actual male/female Table 2 values) and Jones et al. 1997 (PMC2042884, fasted and high-fat meal results). The first study supplies cohort mean mass and nominal 100 mg dosing; the ethanol examples declare a standardized 75 kg participant and 10 minute intake because those individual data were not extracted. The heavy-meal formulation approximates the published breakfast.

The predeclared descriptive discrepancy screen uses reported mean +/- 2 SD. It evaluates transported summary predictions, with no calibration to the benchmark values. Full empirical time-series validation and individual predictive accuracy remain unevaluated by this corpus. User-imported evaluation observations permit trajectory residual analysis. A benchmark-only fed-elimination hypothesis applies 1.39-fold elimination from the 2023 population study (PMID 36688276); the default model is unchanged.

The standardized reference predicts approximately 1.613 and 2.236 mg/L for the male/female caffeine cohorts, compared with published 1.758 and 2.142 mg/L. It predicts 0.02248 and 0.00870 g/dL for fasted/fed ethanol, compared with 0.0308 and 0.0166 g/dL. The feeding hypothesis lowers the fed prediction to approximately 0.00584 g/dL. These discrepancies and reconstruction limits are retained visibly.

## Execution, state and documents

Scientific jobs run in an embedded Blob worker. Worker unavailability uses an explicit cooperative fallback. Cancellation terminates the worker; input changes cancel a running job; prior results retain their captured input identity. Work budgets cap estimated internal integration steps at 2.5 million. Ensembles aggregate a reporting grid and retain draws and summaries instead of every dense trajectory.

Scientific inputs are part of the undoable captured frame. The latest three result records are stored separately from editing history. Session wrapper 1.1.0 imports wrapper 1.0.0 with empty scientific defaults. Scientific profile schema 1.0.0 is validated before restoration. Portable exports are limited to 8 MiB. Main state, scientific state, results, reports, recovery and standalone operation share declared version identities.

## Interface and delivery

The four primary workspaces remain stable. Session adds Observations; Analysis adds a Scientific workbench with Evaluation, Calibration, Uncertainty and Evidence. Scientific depth, reading density and explanation support remain independent. Workbench forms use committed changes and explicit runs. Default, Detailed and Expert guides state actions, expected results and checks.

Production verification includes pkpd.goturbo.one and the independently accessible Pages alias. PR verification uses the exact immutable preview. Both hosted paths verify HTTPS, current manifest identity, worker control, two cached reloads and HTML aliases. Existing offline/update and storage-preservation gates remain required.
